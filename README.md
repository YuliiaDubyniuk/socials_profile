# Socials Profile — React Components

A reusable React component library to build a sleek "link in bio" style social profile page. Great for personal websites, portfolios, and link hub pages.

## Features

- **Modular React components** for social links & profiles  
- **TypeScript support** (if used)  
- Customizable design — easily adapt colors, icons, and layout  
- Responsive layout for mobile and desktop  
- Built with modern tooling (Vite or CRA) for fast dev experience
